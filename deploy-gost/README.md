# Развертывание GOST v3 + nftables Stealth Whitelist

Полный пакет для быстрой миграции прокси-сервера со **Squid** на высокопроизводительный **GOST v3** с защитой портов через ядро Linux (**nftables**).

---

## Ключевые преимущества этой сборки

1. **Потребление оперативной памяти**: ~**15 МБ** (вместо 200–300 МБ у Squid).
2. **Мгновенный вайтлист (0.001 сек)**: добавление IP происходит напрямую в хэш-таблицу ядра Linux `nftables` без перезагрузки прокси и без разрыва активных соединений.
3. **Режим невидимки (Stealth / DROP)**: неавторизованные IP не получают даже ответа «403 Forbidden» — фаервол молча отбрасывает пакеты (`drop`). Для сканеров (Shodan, Censys) и ботов порты прокси выглядят полностью выключенными.
4. **Многопротокольность**:
   - **Порт 3128**: стандартный HTTP CONNECT (100% совместим с Desktop приложением прямо сейчас, менять клиент не требуется).
   - **Порт 8443**: защищенный HTTPS/TLS CONNECT (трафик между вашим ПК и сервером шифруется TLS, скрывая запросы от ТСПУ и провайдерского DPI).
   - **Порт 1080**: высокоскоростной SOCKS5.
5. **Поддержка Telegram-бота**: бот адаптирован и мгновенно открывает доступ через кнопку «Добавить мой IP по ссылке» или команду вручную.

## Содержимое папки

| Файл / Папка | Описание |
| :--- | :--- |
| `install.sh` | **Скрипт автоматической установки** в 1 клик для Ubuntu/Debian. |
| `gost.yaml` | Конфигурация GOST v3 (HTTP :3128, HTTPS :8443, SOCKS5 :1080). |
| `nftables.conf` | Конфигурация фаервола Linux для защиты прокси-портов. |
| `ip_manager.sh` | Высокоскоростной скрипт добавления/удаления IP из ядра Linux. |
| `index.js`, `package.json` | Микросервис Whitelist API (порт 1135) для Desktop-приложения. |
| `systemd/` | Юниты `gost.service`, `whitelist-api.service`, `tg-bot.service`. |
| `tg-bot/` | Адаптированный Telegram-бот управления вайтлистом. |

## Быстрая установка на сервер (1 команда)

### 1. Скопируйте папку `deploy-gost` на ваш сервер:
```bash
scp -r ./deploy-gost root@ВАШ_IP_СЕРВЕРА:/root/deploy-gost
```

### 2. Подключитесь по SSH и запустите установщик:
```bash
ssh root@ВАШ_IP_СЕРВЕРА
cd /root/deploy-gost
chmod +x install.sh ip_manager.sh
./install.sh
```

Скрипт автоматически:
- Установит GOST v3 и `nftables`.
- Мягко отключит старый Squid (освободив порт 3128).
- Перенесет ваши существующие разрешенные IP в новый вайтлист.
- Сгенерирует TLS-сертификаты для HTTPS-прокси.
- Настроит и запустит службы `gost.service`, `whitelist-api.service` и `tg-bot.service`.

## Проверка работы

### Статус служб:
```bash
systemctl status gost
systemctl status whitelist-api
systemctl status tg-bot
```

### Просмотр текущего белого списка в ядре:
```bash
# Просмотр через скрипт:
/usr/local/bin/ip_manager.sh list

# Просмотр хэш-сета nftables напрямую в памяти ядра:
nft list set inet proxy_filter whitelist
```

### Ручное добавление и удаление IP для тестов:
```bash
/usr/local/bin/ip_manager.sh add 178.120.53.202
/usr/local/bin/ip_manager.sh remove 178.120.53.202
```

## Настройка Telegram-бота (по желанию)

Файл бота расположен в `/opt/proxy-tg-bot/bot.py`.
Если требуется настроить токен и админов, отредактируйте параметры в начале файла или передайте через окружение:
```bash
nano /opt/proxy-tg-bot/bot.py
# Задайте SERVER_HOST="ВАШ_IP" и перезапустите службу:
systemctl restart tg-bot
```

## Совместимость с Desktop-приложением Proxy Router

* **Вайтлист**: Приложение на ПК продолжает отправлять запросы на `POST http://ВАШ_IP:1135/api/whitelist`. Никаких изменений в URL не требуется.
* **Прокси**: Приложение подключается к `ВАШ_IP:3128` (через GOST).
* Скорость авторизации вырастает в сотни раз (с 3-5 секунд реконфигурации Squid до 1 миллисекунды в nftables).
