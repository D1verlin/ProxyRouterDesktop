Пошаговые инструкции по настройке сервера VPS (GOST v3), десктопного клиента и виджета для Linux.

Автоматическая установка GOST v3 + nftables на VPS

Поддерживаемые ОС: Ubuntu 20.04 / 22.04 / 24.04 или Debian 11 / 12. Скрипт разворачивает бинарник GOST v3, генерирует TLS-сертификаты, активирует скрытый файрвол nftables и REST API для авторизации IP клиентов.

git clone https://github.com/D1verlin/ProxyRouterDesktop.git /opt/proxy-router && cd /opt/proxy-router/deploy-gost && chmod +x install.sh && sudo ./install.sh

Активные порты и защита сетевого стека

HTTP-прокси: порт 3128
HTTPS (TLS) прокси: порт 8443
SOCKS5-прокси: порт 1080
Whitelist REST API: порт 1135
Токен авторизации: /etc/gost/api_token.txt
Файрвол: Stealth nftables (чужие IP отбрасываются через DROP)
systemctl status gost.service whitelist-api.service

Настройка Proxy Router Desktop для Windows

1. Скачайте последнюю версию приложения из Releases на GitHub и установите его.

2. Откройте вкладку Настройки в приложении:

  • Хост сервера: IP-адрес вашего VPS сервера.
  • API URL: http://YOUR_SERVER_IP:1135
  • Токен авторизации: секретный токен из /etc/gost/api_token.txt.
  • Протокол: выберите HTTP (порт 3128) или SOCKS5 (порт 1080).

3. Включите Авто-вайтлист (Auto Whitelist) — приложение само будет отправлять ваш домашний IP на сервер при запуске.

PAC-режим (:8182): идеален для браузеров. Браузер сам перенаправляет только заданные домены, весь остальной интернет идет напрямую.
Forwarder-режим (:8183): глобальный перехват трафика для Discord, Telegram Desktop, терминалов и IDE.

Виджет верхней панели Omarchy Linux с 3D Кибер-Планетой

Минималистичный нативный виджет для Omarchy / Hyprland / Quickshell. Отображает интерактивную 3D кибер-планетку (Dot-Matrix Earth Sphere), статус подключения (ON / OFF / AUTH...), задержку до VPS в мс и текущий внешний IP.

Установка и регистрация виджета

cd ~/projects && git clone https://github.com/D1verlin/ProxyRouterDesktop.git && cd ProxyRouterDesktop/omarchy-widget && chmod +x install.sh && ./install.sh

Конфигурация (~/.config/proxy-router/settings.json)

proxy_router_ctl.py config

Укажите server.host, server.apiUrl и server.authToken в открывшемся файле.

Управление через CLI и горячие клавиши

proxy_router_ctl.py list — статус сервисов
proxy_router_ctl.py enable <id> — включить
proxy_router_ctl.py connect — коннект
proxy_router_ctl.py disconnect — отключить
Omarchy IPC & Hyprland:
omarchy-shell proxy-router toggle
Добавьте в hyprland.conf:
bind = $mainMod, P, exec, omarchy-shell proxy-router toggle

Управление вайтлистом через Telegram-бота

Бот позволяет моментально авторизовывать ваш IP с любого устройства (смартфон, ноутбук) нажатием одной кнопки в Telegram без входа по SSH.

1. Создайте бота в @BotFather и скопируйте токен.

2. Настройте конфигурационный файл на сервере:

cd /opt/proxy-router/deploy-gost/tg-bot && cp .env.example .env && nano .env

3. Запустите системную службу бота:

systemctl enable --now tg-bot.service && systemctl status tg-bot.service

Команды бота: /start — главное меню, /my_ip — авторизация в 1 клик, /status — список активных IP в вайтлисте.
